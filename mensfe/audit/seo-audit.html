Summary

Mensfe has something most health websites would envy: a long-running, genuine community, credible founders, and a public index of real discussions about male infertility going back to 2007. Search engines can still find the brand (it ranks for its own name and appears in some "male infertility forum" results), but the site is technically stuck in 2007. It is not mobile-friendly, it is served over insecure HTTP on two duplicate domains, it has no working analytics, and it gives Google almost no structured signals about what it is or who stands behind it.

Because Mensfe covers health topics, Google treats it as "Your Money or Your Life" content and holds it to a higher standard of trust. The good news is that most of the trust ingredients already exist; they just are not visible to search engines.

Top five priorities

  1. Make the site mobile-friendly (viewport + responsive layout or a new theme). Google indexes the mobile version first; today's fixed 867px tables are a ranking penalty on every page.
  2. Move to HTTPS on one domain. 301-redirect http:// and mensfe.co.uk to https://www.mensfe.net.
  3. Install Google Analytics 4, Google Search Console and Bing Webmaster Tools. The current tracking script stopped collecting data years ago.
  4. Give every page a proper heading structure, title and description, starting with the homepage and the 12 information pages.
  5. Show who is behind Mensfe. Put the founders' credentials, a medical reviewer and "last reviewed" dates on the information pages, and add Organization, Person and forum structured data.
How this audit was done. The site could not be reached from our audit environment (it requires a VPN from our location), so this review is based on the full homepage source code and rendered screenshots supplied by the client, plus what public search results show about the site's indexed pages on 1 October 2026. Items that need direct access to confirm (robots.txt, XML sitemap, Core Web Vitals, index coverage, backlinks) are listed in section 6 with how to check them.

1. Technical foundations

T1Not mobile-friendly: no viewport, fixed-width table layoutCritical
Evidence
No <meta name="viewport">. The whole page is nested <table width="867"> layouts with fixed pixel widths and inline font sizes.
Impact
Google ranks using the mobile rendering. On a phone the page appears as a shrunken desktop page with tiny text and tap targets, which harms rankings and engagement on every page.
Fix
Rebuild the static pages on a responsive layout and install a responsive SMF theme (see the accompanying redesign concepts). Short-term: add the viewport tag only once the layout can respond to it.
T2Site is indexed on insecure HTTPCritical
Evidence
Search results list http://www.mensfe.net/, http://www.mensfe.net/forum/index.php and other pages on plain HTTP. Internal links (e.g. the forum button) and the analytics script are hard-coded to http://.
Impact
Chrome labels the site "Not secure", including on the forum login and registration pages. HTTPS is a confirmed (light) ranking signal and a strong trust signal for a health community.
Fix
Install a TLS certificate (free via Let's Encrypt), 301-redirect all HTTP URLs to HTTPS, update SMF's forum URL setting, change hard-coded links to relative or HTTPS, then add HSTS.
T3Duplicate site on mensfe.co.ukCritical
Evidence
Search results show http://www.mensfe.co.uk/ with the identical title "Male Infertility and Mens Fertility Forum and Chat" alongside mensfe.net.
Impact
Two copies of the same site split links and authority, and Google (and AI systems) may pick the "wrong" one to show.
Fix
Choose https://www.mensfe.net as the single home. Permanently (301) redirect every mensfe.co.uk URL to the same path on mensfe.net. Verify both in Search Console.
T4No working analytics or Search Console dataCritical
Evidence
The only tracking is urchin.js with property UA-1558618-9, loaded over HTTP. This legacy Google script predates Universal Analytics, and Universal Analytics itself stopped processing data in July 2023.
Impact
Nothing is being measured: no traffic, sources, search queries or conversions. The "6,531,247 visits in 2025" figure on the homepage therefore needs a documented source (e.g. server logs) before it is quoted.
Fix
Remove urchin.js. Install GA4 (with a cookie consent banner for UK visitors), Google Search Console and Bing Webmaster Tools. Submit the sitemap in both.
T5No canonical tags; forum URL variantsHigh
Evidence
No rel="canonical" on the homepage. The forum is linked as both /forum and forum/index.php; SMF exposes parameter URLs (?board=11.0, ?board=11.60, ?topic=97.0) plus print, profile, login and search URLs.
Fix
Add self-referencing canonicals site-wide. In SMF, enable search-engine-friendly URLs, and keep low-value pages (profiles, print views, search results, login, "who's online") out of the index with noindex.
T6Outdated code: HTML 4.01, ISO-8859-1, jQuery 1.10.1High
Evidence
HTML 4.01 Transitional doctype; charset=iso-8859-1; jQuery 1.10.1 (2013) from Google's CDN; Dreamweaver MM_swapImage rollover scripts; invalid markup (border="o", an unclosed <p>, a missing </td></tr>).
Impact
Old jQuery versions have published security vulnerabilities, and Lighthouse flags them. The legacy charset can corrupt characters such as curly quotes and dashes.
Fix
Use <!DOCTYPE html> and UTF-8. Replace rollovers with CSS hover, and update or remove jQuery (the slider can be pure CSS).
T7Forum platform version and theme need reviewHigh
Evidence
The forum runs on Simple Machines Forum (SMF). Its index title is "The Mens Fertility Forum - Mensfe - Index", and the URLs use SMF's default parameter format.
Fix
Confirm the SMF version and upgrade to the current supported release (security and PHP compatibility). Install a responsive theme, enable SEO-friendly URLs, and set descriptive board titles and meta descriptions.
T8Every internal link opens a new tabMedium
Evidence
All navigation links use target="_blank", including About, Mission and all 12 information pages.
Fix
Open internal links in the same tab. Keep _blank only for external links, and add rel="noopener" to them.

2. On-page SEO

P1No H1 or heading structureCritical
Evidence
There are no <h1>–<h3> elements at all. The visual headings ("Welcome to the Men's Fertility Web Site – MENSFE MATTERS", "Male Infertility Support", "FORUM") are styled <span>s.
Fix
One H1 per page that states the topic (homepage: "Male infertility support forum for men"), with H2s for each section. Apply this to all 12 information pages and the forum theme.
P2Title tag and meta descriptionHigh
Evidence
Title (69 characters): "Male Infertility and Mens Fertility Forum and Chat | Help and Support", which is likely to be cut off in results and does not contain the brand. The meta description (~170 characters) opens "A online support web site…" and ends "..".
Fix
Title: "Male Infertility Forum & Support for Men | Mensfe". Description: "Free, anonymous support for men facing infertility: azoospermia, low sperm count, ICSI and IVF. Join the Mensfe forum and talk to men who understand." Write a unique title and description for every information page and forum board.
P3Thin homepage copy; key topics only appear as link textHigh
Evidence
The centre column is a 12-image slider, four empty &nbsp; paragraphs and a quotation. Topics such as azoospermia, semen analysis and varicocele appear only as navigation links.
Fix
Add 300–600 words of real introductory copy explaining who Mensfe is for, what the forum offers and the most common topics, with contextual links to the information pages and boards. Show the latest forum discussions on the homepage.
P4No structured dataHigh
Evidence
No JSON-LD or microdata anywhere on the homepage.
Fix
Homepage: Organization (name, logo, founders, email, sameAs) and WebSite with a SearchAction. Forum topics: DiscussionForumPosting (Google uses it for its "Discussions and forums" features). Information pages: MedicalWebPage with author, reviewedBy and lastReviewed. Book: Book with author Pip Reilly. Everywhere: BreadcrumbList. A starter snippet is in section 7.
P5Obsolete meta tags with misspellingsMedium
Evidence
keywords, keyphrases, Abstract, class, classification, distribution, Title and revisit-after are all ignored by Google. The keywords list also contains "Impotance", "Prostrate" and "Gamette".
Fix
Delete them. Add Open Graph and Twitter card tags so shared links show a proper title, description and image.
P6Copy errors and unclear calls to actionMedium
Evidence
"Share and see all your story's" (should be "stories"), "Mens" (should be "Men's"), "To find out about all the above please click on for link", and an unexplained "(M0D2088113817)" beside the book. The main call to action is a plain text link.
Fix
Proofread all pages. Turn the forum link into a clear button such as "Join the forum, free" or "Read members' stories".
P7Text inside imagesMedium
Evidence
The banner tagline ("You'll never walk alone…… at Mensfe"), the logo and the "Perseverance" quote slide are all images. The banner's alt text describes different words from those shown in the image.
Fix
Use real HTML text for taglines and quotes. Make alt text match what the image shows. Make the logo its own image that links to the homepage.

3. Content, trust and E-E-A-T

E1Founders' expertise is hiddenCritical
Evidence
The About page says Mensfe was founded by Pip Reilly, a professional fertility counsellor with more than 15 years' work with fertility charities, and Rob Barlow, a medical scientist diagnosed with azoospermia more than 25 years ago. None of this appears on the homepage or the information pages, and the About link opens in a new tab.
Impact
For health topics, Google's quality guidelines put heavy weight on demonstrated experience and expertise. Mensfe has both (lived experience and professional counselling) but does not show them.
Fix
Add a "Who runs Mensfe" section to the homepage. Give each founder an author page with a photo and credentials, and mark them up with Person schema linked from Organization.
E2Medical pages lack authorship, review and datesHigh
Evidence
The homepage gives no indication of who wrote or reviewed the information pages, or when. The forum has a "Dear Doctor" expert panel, but its experts are not identified on the main site.
Fix
On every information page, show "Written by", "Medically reviewed by [name, credentials]", "Last reviewed [date]" and a list of sources (NHS, NICE, HFEA, WHO). Review pages at least yearly.
E3Stale signalsHigh
Evidence
The footer reads "© 2007–2025". The homepage still promotes a 2007 conference poster, and the visitor statistic refers to 2025.
Fix
Update the footer year automatically. Replace the 2007 item with recent news or forum activity, and show "updated" dates on content.
E4The forum's value is not surfacedHigh
Evidence
The homepage gives no glimpse of recent discussions, board names or member stories; it shows one "FORUM" text link. Search results for queries like "azoospermia support forum men UK" go to Mumsnet threads and clinics instead.
Fix
Show latest topics and featured boards on the homepage. Link each information page to its matching board, and link boards back to the guides. Write short "community wisdom" summaries for evergreen questions (e.g. "What to ask before micro-TESE").
E5Inconsistent brand namingMedium
Evidence
"Mensfe", "MENSFE MATTERS", "Mens fertility network", "Mensfe – the mens fertility forum", "Men's Fertility Web Site" and "Male Infertility Support Group".
Fix
Pick one name and one descriptor (e.g. "Mensfe — the men's fertility forum") and use them consistently in titles, schema, social profiles and directory listings.
E6Possibly unlicensed stock imagesMedium
Evidence
Slider file names such as happy-couple-7784917 and Autumn-wallpaper-autumn-9444937-1280-1024[1] look like downloads from wallpaper or stock sites, and one image appears to carry a stock watermark.
Fix
Confirm licences or replace the images with licensed or original ones. This is a legal risk as well as a trust issue.

4. Images, performance and accessibility

I1Twelve slider images with empty alt textHigh
Evidence
All 12 slider images have alt="" and meaningless file names (download, thIR60IRP3). One is a .jfif file. None declares width and height, and all of them load on first paint.
Fix
Cut the slider down to one or two meaningful images, or remove it. Use descriptive file names and alt text, WebP/AVIF formats, explicit dimensions and loading="lazy" below the fold.
I2Low colour contrastMedium
Evidence
Olive text on white (the ICSI poster note), light grey on mid-grey (the footer bar) and red on a grey-pink panel.
Fix
Meet WCAG AA contrast (4.5:1 for body text). This also lifts Lighthouse accessibility scores.
I3Render-blocking scripts and preloaded rollover imagesMedium
Evidence
jQuery loads synchronously in <head>. onLoad preloads five rollover images, and the slider script and urchin.js load at the end of the page.
Fix
Remove the rollover JavaScript and jQuery, and defer any scripts that remain. Then measure Core Web Vitals (see section 6).
I4Email address exposed in plain textMedium
Evidence
mailto:info@mensfe.net appears in the page source, where spam harvesters can collect it.
Fix
Use a contact form with spam protection, or obfuscate the address.

5. Off-page and brand visibility

O1Ranks for its brand, weak for non-branded support searchesHigh
Evidence
On 1 October 2026, "mensfe male infertility forum" returned five mensfe pages in the top 10, and "best male infertility support forum online" showed mensfe.net at position 7. Mensfe did not appear in the top 10 for "azoospermia support forum men UK" or "where can men get emotional support for male infertility UK"; those results were led by Mumsnet, Fertility Network UK (HIMfertility), BICA and private clinics.
Fix
Address the technical issues first, then build pages and forum hubs around these support-intent searches (see the AI visibility audit).
O2Existing mentions to build onMedium
Evidence
Mensfe is listed on resource pages for childless men (robinhadley.co.uk, Gateway Women), appears in Fertility Network UK's Affinity magazine (2021) and in International Men's Day UK coverage. It is also a member of iCSI.
Fix
Ask these sites to update their links to the HTTPS domain. Then pursue listings on Fertility Network UK, BICA and clinic resource pages, plus podcast and press opportunities around Pip Reilly's book.
O3No social profiles or sameAs linksMedium
Evidence
The homepage links to no social profiles.
Fix
Claim consistent profiles (Facebook, X/Bluesky, LinkedIn, YouTube or a podcast) and reference them in Organization.sameAs.

7. Roadmap

First 30 days

  • HTTPS and 301 redirects; merge mensfe.co.uk into mensfe.net
  • GA4, Search Console and Bing Webmaster Tools
  • New homepage title, description, H1 and copy
  • Remove obsolete meta tags; add canonical and Open Graph
  • Organization and WebSite schema
  • Fix copy errors and the footer date

Days 31–60

  • Responsive redesign of the static pages
  • Upgrade SMF; responsive theme; SEO-friendly URLs
  • DiscussionForumPosting schema on topics
  • Founder author pages; reviewer and dates on information pages
  • Image clean-up and licence check

Days 61–90

  • Topic hubs linking guides ↔ boards
  • "Community wisdom" pages for top questions
  • Outreach: FNUK, BICA, clinics, book PR
  • Core Web Vitals tuning
  • Monthly reporting from GA4 and Search Console
